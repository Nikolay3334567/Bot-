# YT → Anki Miner

Расширение для Chrome в духе Language Reactor: двойные субтитры на YouTube, перевод слов по клику
и **сохранение фрагментов видео прямо в Anki** — с аудио этой фразы, кадром из видео, переводом
и ссылкой на нужный момент.

## Что умеет

- **Двойные субтитры** поверх видео: оригинал + перевод (на русский или другой язык).
- **Панель справа** со всеми фразами видео: клик по времени — переход, текущая фраза подсвечивается.
- **Клик по слову** — перевод и варианты из словаря.
- **Сохранение в Anki** одной кнопкой: расширение само перематывает на фразу, записывает её звук
  (с небольшим запасом до и после), делает скриншот и создаёт карточку:
  - лицевая сторона: кадр, фраза (выбранное слово выделено), аудио;
  - обратная: перевод фразы, слово и его значение, ссылка `youtu.be/...?t=...`.
- **Автопауза** после каждой фразы, **пауза при наведении** на субтитры, **размытие перевода**.
- Работает и с обычными, и с автоматическими субтитрами (автосубтитры собираются в предложения).

### Горячие клавиши (работают в любой раскладке)

| Клавиша | Действие |
|---|---|
| `A` / `D` | предыдущая / следующая фраза |
| `S` | повторить текущую фразу |
| `Q` | включить/выключить автопаузу |
| `E` | сохранить текущую фразу в Anki |
| `Esc` | закрыть окно перевода |

## Установка

### 1. Anki + AnkiConnect
1. Установите [Anki](https://apps.ankiweb.net/) для компьютера.
2. В Anki: **Инструменты → Дополнения → Получить дополнения**, введите код **`2055492159`** (AnkiConnect).
3. Перезапустите Anki. Во время работы с расширением Anki должен быть открыт.

### 2. Расширение
1. Скачайте этот репозиторий (Code → Download ZIP) и распакуйте.
2. Откройте в Chrome `chrome://extensions`.
3. Включите **Режим разработчика** (переключатель справа вверху).
4. Нажмите **Загрузить распакованное** и выберите папку **`extension`**.
5. Откройте любое видео на YouTube с субтитрами — справа появится панель «YT → Anki».

В меню расширения (иконка на панели Chrome) можно выбрать колоду (по умолчанию `English::YouTube`),
язык перевода, запас времени до/после фразы, включить/выключить аудио и кадр.
Кнопка «Проверить связь» показывает, видит ли расширение Anki.

## Как это работает внутри

- `inject.js` — работает в контексте страницы, получает список дорожек субтитров у плеера и
  перехватывает запросы плеера к `/api/timedtext` (YouTube подписывает их токеном, поэтому при
  необходимости расширение само включает CC, чтобы плеер запросил субтитры).
- `content.js` — панель, субтитры поверх видео, горячие клавиши, запись фрагмента:
  звук пишется через `video.captureStream()` + `MediaRecorder` (формат `.webm`/Opus),
  кадр — через `canvas`.
- `background.js` — перевод (публичный эндпоинт Google Translate, без ключа) и AnkiConnect.
  При первом сохранении создаётся тип заметки **«YT Anki Miner»** с полями
  `Sentence, Translation, Word, WordMeaning, Audio, Image, Source`.

## Ограничения

- Фрагмент записывается в реальном времени: сохранение 4-секундной фразы занимает ~4 секунды
  (видео в это время проигрывает фразу, потом возвращается на прежнее место).
- Аудио сохраняется в `.webm` (Opus). Anki на компьютере и AnkiDroid его воспроизводят;
  старые версии AnkiMobile (iOS) могут не воспроизводить.
- Перевод идёт через неофициальный эндпоинт Google Translate — при очень частых запросах
  Google может временно ограничить доступ.
- YouTube периодически меняет устройство сайта; если панель перестанет появляться —
  скорее всего, нужно поправить селекторы в `content.js`.
