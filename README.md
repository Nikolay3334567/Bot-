# YT → Anki Miner

Расширение для Chrome в духе Language Reactor: двойные субтитры на YouTube, перевод слов по клику
и **сохранение фрагментов видео прямо в Anki** — с аудио этой фразы, кадром из видео, переводом
и ссылкой на нужный момент.

## Что умеет

- **Двойные субтитры** поверх видео и **панель справа** со всеми фразами (клик по времени — переход).
- **Подсветка слов** как в Language Reactor:
  - *Изучаю* — сохранённые вами слова (жёлтые);
  - *К изучению* — следующие по частоте после вашего словарного запаса (голубые);
  - *Редкие* — ещё реже (сиреневые);
  - известные слова (ваш запас по частотному словарю + помеченные «Знаю») не подсвечиваются.
  Цвета, размер запаса и всё остальное настраиваются (⚙ в панели).
- **Наведение на слово** — мгновенный перевод (все слова видео переводятся заранее и кэшируются).
- **Клик** — словарь, кнопки статуса и «в Anki».
- **Колесо мыши (средняя кнопка)** — статус по кругу: Новое → Изучаю → Знаю → Новое.
  «Изучаю» сразу создаёт карточку в Anki (можно отключить).
- **Сохранение в Anki в фоне**: видео не перематывается и не останавливается. Звук всё время пишется
  в память (последние ~4 минуты), фраза вырезается оттуда, края подтягиваются к паузам, чтобы не
  обрезать слова. Аудио — MP3 (играет везде, включая iPhone). Если фраза ещё не прозвучала до конца,
  карточка уйдёт в Anki, как только она доиграет.
- **Карточка**: кадр, фраза с выделенным словом, аудио; на обороте — перевод, значение слова и
  кнопка «▶ Смотреть на YouTube · 1:23» с таймкодом.
- **✨ ИИ-обработка (Gemini, по желанию)**: расставляет пунктуацию, собирает полные предложения и
  переводит их по контексту. Результат кэшируется.
- **Словарь** на странице настроек: поиск, смена статуса, импорт списка слов (txt/csv), экспорт.

### Управление

| Действие | Что делает |
|---|---|
| наведение на слово | перевод |
| клик по слову | словарь + кнопки |
| колесо по слову | Новое → Изучаю → Знаю |
| `1` / `2` / `0` при наведении | Изучаю / Знаю / Новое |
| `A` / `D` | предыдущая / следующая фраза |
| `S` | повторить фразу |
| `Q` | автопауза вкл/выкл |
| `E` | текущая фраза в Anki |

## Установка

### 1. Anki + AnkiConnect
1. Установите [Anki](https://apps.ankiweb.net/) для компьютера.
2. В Anki: **Инструменты → Дополнения → Получить дополнения**, введите код **`2055492159`** (AnkiConnect).
3. Перезапустите Anki. Во время работы с расширением Anki должен быть открыт.

### 2. Расширение
1. Скачайте этот репозиторий (Code → Download ZIP) и распакуйте.
2. Откройте в Chrome `chrome://extensions`.
3. Включите **Режим разработчика** (переключатель справа вверху).
4. Нажмите **Загрузить распакованное** и выберите папку **`extension`**.
5. Откройте любое видео на YouTube с субтитрами — справа появится панель «YT → Anki».

В меню расширения (иконка на панели Chrome) можно выбрать колоду (по умолчанию `English::YouTube`),
язык перевода, запас времени до/после фразы, включить/выключить аудио и кадр.
Кнопка «Проверить связь» показывает, видит ли расширение Anki.

### 3. ИИ-обработка (по желанию)
1. Откройте [Google AI Studio → API keys](https://aistudio.google.com/apikey), нажмите **Create API key**
   (можно выбрать ваш проект Google Cloud). Для оплаты сверх бесплатного лимита к проекту
   должен быть привязан биллинг.
2. В расширении: ⚙ → «ИИ-обработка» → вставьте ключ, включите.
3. Модель по умолчанию `gemini-2.5-flash-lite` — самая дешёвая. Примерно $0.002 за 10 минут видео,
   то есть час видео в день ≈ $0.4 в месяц. `gemini-3.1-flash-lite` — около $1.5 в месяц.

### 4. Свой словарь
⚙ → «Мой словарь» → вставьте слова (по одному в строке) или загрузите .txt/.csv → «как Знаю» или
«как Изучаю» → Импортировать. Из Language Reactor: экспортируйте сохранённые слова в CSV и
загрузите файл — берётся первая колонка.

## Как это работает внутри

- `inject.js` — работает в контексте страницы, получает список дорожек субтитров у плеера и
  перехватывает запросы плеера к `/api/timedtext` (YouTube подписывает их токеном, поэтому при
  необходимости расширение само включает CC, чтобы плеер запросил субтитры).
- `content.js` — панель, субтитры, подсветка, горячие клавиши, фоновая запись звука:
  звук снимается через `video.captureStream()` + Web Audio в кольцевой буфер и кодируется в MP3,
  кадр — через `canvas`.
- `background.js` — перевод (публичный эндпоинт Google Translate, без ключа) и AnkiConnect.
  При первом сохранении создаётся тип заметки **«YT Anki Miner»** с полями
  `Sentence, Translation, Word, WordMeaning, Audio, Image, Source`.

## Ограничения

- Аудио берётся из того, что уже прозвучало. Если сохранить фразу, которая ещё не играла
  (например, из списка далеко впереди), карточка подождёт, пока вы до неё дойдёте. Если уйти со
  страницы раньше — карточка добавится без аудио.
- На скорости воспроизведения ≠ 1× аудио в карточке будет на этой же скорости.
- Статусы слов привязаны к форме слова (`run` и `running` — разные). Для частотной подсветки
  простые формы (‑s, ‑ed, ‑ing…) распознаются.
- Перевод слов и фраз без ИИ — через неофициальный эндпоинт Google Translate. При очень частых
  запросах Google может временно ограничить доступ.
- YouTube периодически меняет устройство сайта. Если панель перестанет появляться,
  скорее всего, нужно поправить селекторы в `content.js`.
