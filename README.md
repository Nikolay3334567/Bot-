# YT → Anki Miner

Расширение для Chrome в духе Language Reactor: двойные субтитры на YouTube, перевод слов по клику
и **сохранение фрагментов видео прямо в Anki** — с аудио этой фразы, кадром из видео, переводом
и ссылкой на нужный момент.

## Что умеет

- **Кнопка в плеере YouTube** (внизу, рядом со временем): **YA ON ⚙** — включить/выключить и открыть
  окно настроек как в Language Reactor (вкладки *Вид · Слова · Управление · Перевод · Anki · ИИ*,
  слева — горячие клавиши). Всё применяется сразу и запоминается.
- **Субтитры поверх видео** на фиксированной высоте — не прыгают, когда YouTube показывает/прячет
  панель. Высоту меняйте кнопкой ⌃⌄ справа на видео (тяните мышью или крутите колесо — показывается
  полупрозрачный прямоугольник) или ползунком в настройках. Полупрозрачная подложка, шрифт, размер,
  насыщенность, режим двух строк — во вкладке «Вид».
- **Кнопки по бокам видео**: слева ‹ ↻ › (фразы), справа переключатель **AP** (автопауза) и ⌃⌄.
- **Пауза при наведении** на всю строку субтитров вместе с подложкой — без дёрганья между словами.
- **Цвета как в Language Reactor**: зелёные — известные, оранжевые — рекомендованные,
  фиолетовые — не учить/редкие, **в рамке** — изучаемые (в Anki).
- **Подсказка при наведении**: варианты перевода столбиком, выражения («figured it out» 📖),
  кнопки ✓ / 📖. Размер текста, число вариантов и плавность появления настраиваются.
- **Клик по слову** — окно сразу в итоговом размере, привязано стрелкой к слову: вкладки ИИ
  «Объяснить / Примеры / Грамматика» (промпты редактируются), вопрос к ИИ, словарь, примеры из видео,
  ссылки на словари (+ свои), ✓ / 📖 / ⊘. **Повторный клик закрывает окно**, видео продолжается.
  Слово может произноситься при открытии.
- **Правая кнопка мыши** — Знаю ⇄ Изучаю (можно переназначить). «Изучаю» = карточка в Anki.
- **Боковая панель**: вкладки *Субтитры / Слова / Сохранённые*, полоса прогресса ИИ и перевода.
  «Слова» — все слова видео по частоте со счётчиками ✓ 📖 ⊘. «Сохранённые» — список с 🗑.
- **Синхронизация с Anki**: если слово убрано из изучаемых (🗑, «не учить», сброс), его карточка
  удаляется из Anki через 30 секунд (настраивается).
- **Чистый звук через yt-dlp** (лончер в папке `launcher`), запасной путь — запись с видео.
- **Прогресс из Anki**: рамка слова меняет цвет от оранжевого к зелёному по интервалу карточки; выученные
  карточки сами становятся «Знаю».
- **Режим паузы при наведении**: по умолчанию — только когда фраза доиграла до конца (можно «сразу»); индикатор AP краснеет, когда
  воспроизведение удержано.
- **Любой ИИ**: Gemini (по умолчанию `gemini-3.5-flash-lite`) или любой OpenAI-совместимый адрес (OpenRouter, Ollama, DeepSeek…), свои заголовки,
  промпты и параметры.
- **Перевод и озвучка через Google Cloud** (по желанию, [инструкция](docs/GOOGLE_CLOUD.md)): 500 000 знаков перевода в месяц
  бесплатно; субтитры и слова переводятся пакетами заранее, подсказка мгновенная. Встроенный счётчик и предел
  не дают выйти за бесплатный лимит — после него расширение само переходит на бесплатный перевод.
- **Паузы с музыкой под голосом**: тишина ищется в полосе речи относительно уровня фона, а не «абсолютной тишины»;
  если речь не заметно громче фона, расширение честно берёт время YouTube (как в 5.0).
- **Очередь Anki**: если Anki закрыт, карточка (со звуком и кадром) сохраняется и уходит сама, как только он откроется
  (проверка раз в минуту и по кнопке ⟳ в панели или меню расширения; число в очереди — на значке).
- **Сайт, тарифы и калькулятор** — папка `site` (см. ниже).
- **Меню разработчика 🛠**: все внутренние параметры ползунками, прослушивание клипа.
- **Сохранение в фоне**: видео не перематывается; MP3 с подгонкой краёв по паузам; кадр; перевод;
  ссылка «▶ Смотреть на YouTube» с таймкодом.
- **✨ ИИ (Gemini)**: «Текст» (пунктуация, предложения, перевод, выражения) или
  «🎧 Слушает видео» (точный текст по звуку, работает и без субтитров).

### Управление

| Действие | Что делает |
|---|---|
| наведение на слово | подсказка |
| клик по слову | подробное окно; повторный клик — закрыть |
| правая кнопка / колесо | Знаю ⇄ Изучаю (+ карточка) |
| `1` / `2` / `3` / `0` при наведении | Изучаю / Знаю / Не учить / сброс |
| ☆, `R` или `E` | фраза в Anki |
| `A` / `S` / `D` | пред. / повтор / след. фраза (по желанию — стрелки ← →) |
| `Q` | автопауза |
| `Ctrl+C` | скопировать текущую фразу |
| зажать `Alt` и вести курсором по словам | выделение своей фразы (клавиша меняется в ⚙ → Управление); отпустить — перевод и кнопка «В Anki» (`Enter`), `Esc` — отмена |
| `Shift` + клик по слову | сохранить выражение, на которое попало слово (если выбран такой способ) |
| `Ctrl` при наведении | сделать подсказку кликабельной (режим по умолчанию) |

### Оригинал ↔ ИИ в карточках (⚙ → Фразы / Anki)

Три независимых «градации», все с точным соотношением (не случайным): 50% значит каждая вторая карточка.
- **Голос:** только звук из видео · звук из видео + голос ИИ (второе поле `AudioAI`) · только голос ИИ · «часть карточек голосом ИИ» (доля в %).
  Голоса из списка чередуются по кругу.
- **Текст:** длинные фразы можно обрезать до осмысленного куска со словом (по правилам или через ИИ, в фоне) — а «доля длинных фраз,
  которые обрезаются» задаёт, какая часть остаётся целиком, как в видео.
- **Субтитры:** режим ИИ (⚙ → ИИ) заменяет субтитры обработанными; выкл — оригинальные.

В «Сохранённых» у каждой карточки видно, как она сделана: «🔊 из видео / голос ИИ / видео + ИИ» и «✂ обрезано».

## Установка

### 1. Anki + AnkiConnect
1. Установите [Anki](https://apps.ankiweb.net/) для компьютера.
2. В Anki: **Инструменты → Дополнения → Получить дополнения**, введите код **`2055492159`** (AnkiConnect).
3. Перезапустите Anki. Во время работы с расширением Anki должен быть открыт.

Если после обновления AnkiConnect связь пропала — ⚙ → Anki → «Проверить связь с Anki» покажет, что именно не так.
Расширение само пробует `127.0.0.1`, `localhost`, просит у Anki разрешение (`requestPermission`), учитывает ключ
`apiKey` (поле «Ключ AnkiConnect») и, если запущен лончер, обходит ограничения источника через него. Подробнее —
`docs/ANKI.md`.

### 2. Расширение
1. Скачайте этот репозиторий (Code → Download ZIP) и распакуйте.
2. Откройте в Chrome `chrome://extensions`.
3. Включите **Режим разработчика** (переключатель справа вверху).
4. Нажмите **Загрузить распакованное** и выберите папку **`extension`**.
5. Откройте любое видео на YouTube с субтитрами — справа появится панель «YT → Anki».

В меню расширения (иконка на панели Chrome) можно выбрать колоду (по умолчанию `English::YouTube`),
язык перевода, запас времени до/после фразы, включить/выключить аудио и кадр.
Кнопка «Проверить связь» показывает, видит ли расширение Anki.

### 3. Лончер: чистый звук, запуск Anki (рекомендуется)

**Лончер** — маленькая программа (`.exe`, без Python и pip), которая работает рядом с расширением:

- один раз скачивает аудиодорожку видео через **yt-dlp** и вырезает фразы через **ffmpeg** — звук без
  обрывов, можно сохранять даже ещё не прослушанные фразы;
- **запускает Anki** (нужен AnkiConnect) и может стартовать вместе с Windows;
- показывает окно состояния на http://localhost:8766/ (кнопки: запустить Anki, обновить yt-dlp,
  очистить кэш, автозапуск, журнал).

**Запуск (Windows) — проще всего двойным щелчком по `START.bat`** в корне папки (или `launcher\run.bat`). Он сам:
определяет, какой у вас процессор (ARM64 или Intel/AMD), снимает метку «скачано из интернета», останавливает старую
копию лончера, запускает нужный exe, ждёт, пока он ответит, и открывает страницу состояния. Если exe нет, а Go
установлен, соберёт его. Если что-то пошло не так — покажет последние строки журнала `launcher.log`.

**Chrome одним ярлыком.** На странице лончера (http://127.0.0.1:8766/) есть блок «Chrome: мой профиль + YouTube +
последнее видео»: выберите профиль Chrome (тот, где стоит расширение и выполнен вход в YouTube), отметьте «Открывать
Chrome при запуске лончера» и нажмите «Создать ярлык на рабочем столе». Двойной щелчок по ярлыку «YouTube + Anki»
запускает лончер, Anki и Chrome с вашим профилем на **последнем видео с того же места** (расширение само сообщает лончеру,
что вы смотрите; отключается в ⚙ → Anki). Можно открывать и главную YouTube, и свой адрес. Если лончер уже запущен, ярлык
просто открывает Chrome. Автозапуск с Windows Chrome не открывает.

Вручную: папка `launcher/dist`
- `ytam-launcher-windows-arm64.exe` — для Windows на ARM (Snapdragon);
- `ytam-launcher-windows-amd64.exe` — для обычного Windows (Intel/AMD).

Лончер сам проверяет каждый найденный `yt-dlp*` запуском с `--version` и пропускает тот, что не подходит
вашему ПК (например `yt-dlp_arm64.exe` на обычном Windows даёт «This version of %1 is not compatible…») — тогда он
скачает подходящий. Сборка только под ваш ПК: `launcher\build.bat`, под оба: `launcher\build.bat all`.

Если оба yt-dlp и ffmpeg лежат рядом с лончером (в той же папке или в `bin`) — он берёт их (подойдёт и ваш
`yt-dlp_arm64.exe`: имя может быть любым, начинаясь с `yt-dlp`). Если их нет — лончер скачает сам
(отключается в окне состояния, пункт «Скачивать автоматически»).

**Антивирус ругается?** Это частая реакция на любые неподписанные программы, которые скачивают и запускают
другие `.exe`. Что делать:
1. Соберите лончер **сами из исходников** — `launcher/build.bat` (нужен Go: `winget install GoLang.Go`) либо
   запустите workflow *Build launcher* на GitHub (Actions → Run workflow, потом скачайте артефакт). Собранный у вас
   файл антивирус знает хуже всего, но и «чужой хеш» вызывает меньше подозрений, чем подозрительное поведение.
2. Отключите автоскачивание и положите `yt-dlp.exe` и `ffmpeg.exe` вручную — тогда лончер ничего не загружает.
3. Добавьте папку лончера в исключения антивируса (Защитник Windows → Защита от вирусов → Исключения).
4. Для продажи программу нужно **подписывать сертификатом** (Authenticode / Azure Trusted Signing) — иначе
   SmartScreen будет предупреждать пользователей.

Настройки лончера — в `config.json` рядом с ним (пути к yt-dlp/ffmpeg/Anki, свои аргументы yt-dlp,
размер кэша). Если yt-dlp пишет про JavaScript runtime — установите Deno: `winget install DenoLand.Deno`.

Если лончер не запущен, расширение берёт звук прежним способом (запись с видео). Источник выбирается
в ⚙ → Anki → «Откуда брать звук».

> ⚠️ Скачивание аудио с YouTube нарушает условия YouTube, а Chrome Web Store не принимает такие расширения.
> Используйте лончер как личный инструмент; для публичной версии см. `docs/BUSINESS.md`, раздел 5.


### Откуда берётся перевод и что делать, если его нет

Цепочка для фраз и слов: **Google Cloud** (если задан ключ, 500 000 знаков в месяц бесплатно) → **бесплатный Google** →
**бесплатный переводчик Edge** (запасной, включается сам, когда Google не отвечает или отдаёт ошибку 429). Поэтому без ИИ и
без ключа перевод субтитров всё равно появляется.
- Фраза на экране переводится вне очереди: пока идёт общий перевод, она не ждёт, а до перевода показывается «…».
- Не получившиеся куски перевода повторяются с нарастающими паузами (до 6 раз), кнопка «Сейчас» в панели повторяет сразу.
- Подсказка по наведению показывает перевод сразу, а варианты слова («но / однако / зато…») подтягиваются следом и
  дорисовываются, не задерживая подсказку.
- Субтитр не мигает в «хвосте» фразы: паузы между словами перекрываются (⚙ → 🛠 «Держать субтитр в паузах между словами»).

### Меню разработчика 🛠

Вкладка **🛠** в боковой панели: все внутренние параметры (обрезка звука, пороги тишины,
окна поиска, тайминги субтитров, задержки подсказки, подгрузка словаря, параметры ИИ,
качество кадра…) — ползунками и числами, применяются сразу. Кнопка **«▶ Клип текущей фразы»**
проигрывает, как прозвучит карточка, и показывает границы клипа. «Экспорт/Импорт» — сохранить
набор параметров в JSON. Те же параметры есть во вкладке **«Разработчик»** окна настроек (кнопка ⚙ в плеере и страница настроек). Параметр «Панель отладки на видео = 1» показывает время, фразу,
состояние помощника.

### 4. ИИ-обработка (по желанию)
1. Откройте [Google AI Studio → API keys](https://aistudio.google.com/apikey), нажмите **Create API key**
   (можно выбрать ваш проект Google Cloud). Для оплаты сверх бесплатного лимита к проекту
   должен быть привязан биллинг.
2. В расширении: ⚙ → «ИИ» → вставьте ключ и выберите режим («Текст» или «🎧 Слушает видео»).
3. Модель по умолчанию `gemini-2.5-flash-lite`. Примерная стоимость: текст ≈ $0.002 за 10 мин видео;
   «слушает видео» ≈ $0.01 за 10 мин (30-минутное видео ≈ $0.03); разбор слова ≈ $0.0002.
   Час видео в день в режиме «слушает» ≈ $2–4 в месяц. Повторный просмотр бесплатен (кэш).
   Режим «слушает» работает только для публичных видео.

### 5. Свой словарь
⚙ → «Мой словарь» → вставьте слова (по одному в строке) или загрузите .txt/.csv → «как Знаю» или
«как Изучаю» → Импортировать. Из Language Reactor: экспортируйте сохранённые слова в CSV и
загрузите файл — берётся первая колонка.

## Как это работает внутри

- `inject.js` — работает в контексте страницы, получает список дорожек субтитров у плеера и
  перехватывает запросы плеера к `/api/timedtext` (YouTube подписывает их токеном, поэтому при
  необходимости расширение само включает CC, чтобы плеер запросил субтитры).
- `content.js` — панель, субтитры, подсветка, горячие клавиши, фоновая запись звука:
  звук снимается через `video.captureStream()` + Web Audio в кольцевой буфер и кодируется в MP3,
  кадр — через `canvas`.
- `background.js` — перевод (публичный эндпоинт Google Translate, без ключа) и AnkiConnect.
  При первом сохранении создаётся тип заметки **«YT Anki Miner»** с полями
  `Sentence, Translation, Word, WordMeaning, Audio, Image, Source`.

## Ограничения

- Аудио берётся из того, что уже прозвучало. Если сохранить фразу, которая ещё не играла
  (например, из списка далеко впереди), карточка подождёт, пока вы до неё дойдёте. Если уйти со
  страницы раньше — карточка добавится без аудио.
- На скорости воспроизведения ≠ 1× аудио в карточке будет на этой же скорости.
- Статусы слов привязаны к форме слова (`run` и `running` — разные). Для частотной подсветки
  простые формы (‑s, ‑ed, ‑ing…) распознаются.
- Перевод слов и фраз без ИИ — через неофициальный эндпоинт Google Translate. При очень частых
  запросах Google может временно ограничить доступ.
- YouTube периодически меняет устройство сайта. Если панель перестанет появляться,
  скорее всего, нужно поправить селекторы в `content.js`.

Частотный словарь — [wordfreq](https://github.com/rspeer/wordfreq) (CC BY-SA 4.0),
MP3 — [lamejs](https://github.com/zhuker/lamejs) (LGPL).

## Сайт и тарифы (локально)

Папка `site/` — заготовка официального сайта: лендинг, тарифы, вход, кабинет, калькулятор экономики.
Запустите лончер и откройте **http://localhost:8766/site/**. Вход для теста: **admin / admin**.
Вход через Google, расчёт тарифов, защита репозитория и авторских прав — в [`docs/BUSINESS.md`](docs/BUSINESS.md).
