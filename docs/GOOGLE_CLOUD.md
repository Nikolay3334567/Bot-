# Google Cloud: бесплатный перевод и озвучка

Расширение умеет переводить и озвучивать слова через **Google Cloud** (Cloud Translation и
Text-to-Speech). Это надёжнее бесплатного неофициального переводчика: субтитры целого видео
переводятся заранее одним запросом, перевод по наведению появляется мгновенно, нет сбоев из-за
ограничений частоты.

## Что бесплатно

| Сервис | Бесплатно каждый месяц | Дальше |
|---|---|---|
| Cloud Translation, Basic (v2) | **500 000 знаков** | $20 за 1 млн знаков |
| Text-to-Speech, голоса Standard | **4 млн знаков** | $4 за 1 млн |
| Text-to-Speech, голоса Neural2 | **1 млн знаков** | $16 за 1 млн |

Источники: [цены Translation](https://cloud.google.com/products/translate/pricing),
[цены Text-to-Speech](https://cloud.google.com/text-to-speech/pricing). Цены меняются — сверьтесь
в консоли: «Billing» → «Pricing».

**Важно про ваш случай.** Трёхмесячный пробный период с $300 — это одно, а ежемесячный бесплатный лимит —
другое: он **не заканчивается** с пробным периодом. Но API работает только если к проекту привязан
платёжный аккаунт; пока вы не превышаете лимит, списаний нет. Выше лимита деньги списываются —
поэтому ниже три слоя защиты.

## Подключение за 5 минут

1. Откройте [console.cloud.google.com](https://console.cloud.google.com/), выберите свой проект
   (или создайте новый и привяжите к нему платёжный аккаунт).
2. **Включите API:** меню ☰ → «APIs & Services» → «Library» → найдите и нажмите «Enable» у
   **Cloud Translation API** и **Cloud Text-to-Speech API**.
3. **Создайте ключ:** «APIs & Services» → «Credentials» → «Create credentials» → «API key».
   Скопируйте его.
4. **Ограничьте ключ** (чтобы им нельзя было пользоваться для чего-то ещё): нажмите на ключ →
   «API restrictions» → «Restrict key» → отметьте только эти два API → «Save».
5. **Вставьте ключ в расширение:** ⚙ (в плеере YouTube или значок расширения → «Все настройки») →
   вкладка **«Перевод»** → поле «Ключ Google Cloud» → кнопка **«Проверить ключ Google Cloud»**.
   Должно появиться «Перевод: … · Озвучка: ok».

Ключ хранится только на вашем компьютере (в `chrome.storage.local`, не синхронизируется и не попадает в
репозиторий).

## Как не заплатить лишнего (три слоя защиты)

1. **Встроенный счётчик расширения** (включён по умолчанию). Во вкладке «Перевод» показано, сколько
   знаков израсходовано в этом месяце. Пределы по умолчанию: перевод **450 000** (с запасом до 500 000),
   озвучка **900 000** (с запасом до 1 млн, на случай голосов Neural2). Дойдя до предела, расширение
   **само переключается** на бесплатный перевод и голос браузера. Если используете голоса Standard —
   предел озвучки можно поднять до 3 500 000.
2. **Квота на стороне Google** (жёсткий потолок). «APIs & Services» → «Enabled APIs» →
   Cloud Translation API → «Quotas & System Limits» → найдите квоту на **символы в день**
   («characters per day» в рамках проекта) → карандаш → поставьте, например, **15 000** (≈ 450 000 в
   месяц). То же для Text-to-Speech. Названия квот в интерфейсе меняются, ориентируйтесь на слово
   *characters*. Выше квоты Google просто вернёт ошибку, а расширение продолжит бесплатным путём.
3. **Бюджет с оповещением.** «Billing» → «Budgets & alerts» → «Create budget» → сумма $1 →
   оповещения на почту при 50% и 100%. (Бюджет только предупреждает, но не останавливает расходы —
   поэтому он третий слой, а не первый.)

## Сколько хватает бесплатного лимита

- Субтитры 10-минутного видео — примерно 8–11 тыс. знаков (предложения + уникальные слова).
  500 000 знаков ≈ **45–60 десятиминутных видео в месяц**.
- Перевод слов при наведении кэшируется навсегда: повторные слова ничего не стоят.
- Озвучка слова — около 8 знаков, результат тоже кэшируется. 1 млн знаков — это >100 тысяч слов.
- Видео, которое вы уже смотрели, повторно не переводится (кэш).

## Что и откуда берётся

- **Перевод предложений и слов** — Cloud Translation (пакетами: до 100 строк за запрос).
- **Варианты слова столбиком в подсказке** — бесплатный словарь Google (если он отвечает за 1,5 с).
  Cloud Translation даёт один перевод, а не список вариантов. Отключается переключателем
  «Варианты слова для подсказки».
- **Озвучка** — голос Google (по умолчанию `en-US-Neural2-F`, меняется в настройках), запасной вариант —
  голос браузера.
- **ИИ-разбор слова и «слушает видео»** — Gemini по отдельному ключу (вкладка «ИИ»); он не связан с этим ключом.

## Если что-то не работает

| Сообщение | Причина |
|---|---|
| `Cloud Translation: API has not been used…` | API не включён в этом проекте (шаг 2). |
| `API key not valid` / `blocked` | Ключ скопирован не целиком или ограничен не теми API (шаг 4). |
| `billing` в тексте ошибки | К проекту не привязан платёжный аккаунт. |
| В подсказке один вариант вместо списка | Бесплатный словарь не ответил — это нормально. |
| Счётчик упёрся в предел | Расширение ушло на бесплатный перевод; в начале следующего месяца счётчик обнулится. |
