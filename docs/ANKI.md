# Связь с Anki (AnkiConnect)

Расширение говорит с Anki через дополнение **AnkiConnect** (код `2055492159`). После обновления AnkiConnect
чаще всего ломается одно из трёх. Кнопка **⚙ → Anki → «Проверить связь с Anki»** покажет, какое именно.

| Что видно | Причина | Что сделать |
|---|---|---|
| «Нет связи с Anki» | Anki закрыт, нет AnkiConnect или занят порт 8765 | Откройте Anki; проверьте дополнение; адрес в поле «Адрес AnkiConnect» |
| «HTTP 403 … webCorsOriginList» | AnkiConnect не пускает адрес расширения | Anki → Инструменты → Дополнения → AnkiConnect → Config → в `webCorsOriginList` добавьте адрес из сообщения (`chrome-extension://…`) или `"*"`, перезапустите Anki. **Или** запустите лончер (`START.bat`) — он передаёт запросы без заголовка Origin |
| «нужен ключ AnkiConnect» | В конфиге AnkiConnect задан `apiKey` | Впишите тот же ключ в поле «Ключ AnkiConnect» (хранится только на этом компьютере) |
| «collection is not available» | Anki ещё загружает профиль / идёт синхронизация | Подождите — расширение повторяет запрос само (до 4 раз) |

Как расширение подключается (по порядку, запомнив рабочий маршрут):
1. адрес из настроек (по умолчанию `http://127.0.0.1:8765`), затем `127.0.0.1` и `localhost`;
2. при ответе 403 — запрос `requestPermission` (Anki покажет окно подтверждения);
3. через лончер (`http://127.0.0.1:8766/anki`), который обращается к Anki сам, без Origin.

Тип заметок **YT Anki Miner** обновляется автоматически: недостающие поля (например `AudioAI`) добавляются, шаблоны
синхронизируются, лишние поля, которых нет в вашей версии типа, пропускаются.

## Колода — главная

Включено по умолчанию («Колода главная: подтягивать все слова колоды»):
- все слова колоды (и добавленные не расширением; берётся поле `Word`/`Front`/`Expression` или первое поле) появляются
  во вкладке «Сохранённые» как «изучаю» с пометкой «колода Anki»;
- слово, чью карточку вы удалили в Anki, пропадает из «Сохранённых»;
- **удалять расширение может только свои карточки** (с тегом `yt-anki-miner`) — у чужих в списке замок 🔒, а
  запрос на удаление такой карточки отклоняется на стороне расширения.
