Ключ доступа расширения

Вставьте в расширении: ⚙ → ИИ → «Ключ API» (когда подключим сервер ИИ). Пока что можно использовать свой ключ Gemini.

🧪 Тестовый режим: тариф переключается без оплаты.

1. Расширение для Chrome

chrome://extensions → «Режим разработчика» → «Загрузить распакованное» → папка extension.

2. Anki + AnkiConnect

Установите Anki и дополнение AnkiConnect (код 2055492159).

3. Лончер (чистый звук)

Запустите launcher/dist/ytam-launcher-windows-arm64.exe (или amd64). Он сам скачает yt-dlp и ffmpeg, запустит Anki. Статус: localhost:8766.

4. ИИ

⚙ → ИИ: ключ Gemini или любой OpenAI-совместимый адрес (OpenRouter, Ollama, DeepSeek…).

Калькулятор экономики подписки. Цены токенов — Gemini 2.5 Flash-Lite по умолчанию; меняйте, чтобы проверить сценарии.
